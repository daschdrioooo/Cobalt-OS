# Cobalt-OS

Welcome to Cobalt OS!

This is a web OS I'm making for Hack Club's Macondo YSWS. I've loosely followed the Web-OS 1 hack club jam for the first bits, such as the welcome screen, top bar and the notes app. This is also my first ever project with a backend or database. I'm using the database to save data from the notes app, and the backend has my API key for "Cobalt AI" so that it's kept private. I also added a terminal, which my friend Carbon helped me out with a lot!

While making this project, I've learnt a lot more JavaScript which I didn't know previously, and I've learnt how to use a backend and database on a website!

Thanks for checking this out!

Credits: I used W3Schools' dragging function for the windows, check the comment on script.js. Also, I used LuminSDK for the games. Thanks to Carbon (https://github.com/carbonicality) for letting me use his v86 files!
